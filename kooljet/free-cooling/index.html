FREE COOLING

Use cool outdoor air when the temperature outside can satisfy the room’s cooling demand.

Discuss this application

How it works

An ambient sensor controls a motorized damper and fans. When conditions permit, these components admit outdoor air to cool the room, reducing the time mechanical refrigeration has to operate.

System details

  • Outdoor temperature sensor
  • Automatic motorized air damper
  • Reduced compressor run time
